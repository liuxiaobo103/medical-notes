AE急性期免疫治疗 | IVIG / 丙种球蛋白

自身免疫性脑炎：丙球怎么用？

核心思路：疑似或确诊自身免疫性脑炎（AE）且感染等替代诊断已同步评估后，IVIG属于一线免疫治疗选择之一。常用总量 2 g/kg，分 2-5天；临床最常见写法是 0.4 g/kg/日 x 5天。

临床提示：本页用于临床学习和医嘱思路整理，不替代个体化医嘱。具体处方需结合患者年龄、体重、肾功能、血栓风险、过敏史、容量状态、产品说明书及本院药事规范；必要时完成血制品、费用、超说明书/自费等知情同意。

总量 2 g/kg；也可按 2 g/kg 分 2-5日输注。若 2.5 g/瓶，总瓶数约为体重 x 0.8。

治疗定位

IVIG通常不是孤立使用，而是AE急性期一线免疫治疗的一部分。高度疑似或抗体阳性时，可在排查感染等替代诊断的同时尽早启动。

疑似AE

先抓临床综合征

亚急性精神行为异常、癫痫、意识障碍、运动障碍、自主神经紊乱等；同步完善MRI、EEG、CSF、血清+CSF抗体。

同步排查

感染未排除时要谨慎

若HSV等感染性脑炎仍不能排除，应先覆盖抗感染/抗病毒并动态复评，避免盲目免疫抑制。

一线免疫

甲强龙 +/- IVIG

轻-中症可用甲泼尼龙冲击 +/- IVIG；重症/ICU常考虑联合一线，低通气或重度自主神经紊乱时早期评估血浆置换。

剂量与瓶数

推荐剂量

标准冲击量

IVIG 总量 = 体重 kg x 2 g/kg 常用拆分 = 体重 kg x 0.4 g/kg/日 x 5日

速度和总容量需看产品浓度、患者耐受和心肾功能。

2.5 g/瓶计算

瓶数公式

每日瓶数 = 体重 x 0.4 ÷ 2.5 总瓶数 = 体重 x 0.4 x 5 ÷ 2.5 = 体重 x 0.8

实际开具时按药房规格、整瓶规则、剩余量处理和本院规则取整。

给药顺序

注意PLEX会清除IVIG

若准备血浆置换，需统筹顺序；通常避免IVIG后马上PLEX，以免刚输注的免疫球蛋白被清除。

输注前评估与监测

先找出会让IVIG变危险的风险点，重点是肾损伤、血栓、过敏/IgA缺乏、容量负荷和高黏滞状态。

肾功能/尿量

Scr、eGFR、尿量；脱水、老年、糖尿病、肾病、脓毒症、使用肾毒性药物者需格外谨慎。

血栓风险

既往血栓、长期卧床、肿瘤、高凝、中心静脉导管、高黏滞状态、心血管危险因素。

过敏风险

既往IVIG/血制品反应、IgA缺乏史；输注中观察皮疹、喘憋、低血压等。

容量负荷

心衰、肾衰、低氧或容量敏感患者需控制速度、浓度和补液策略。

输注期间：低速起始，耐受后逐步加速；监测生命体征、头痛/发热/寒战、过敏表现、尿量/肌酐、血栓事件和容量超负荷。

哪些情况要特别谨慎？

  • 轻度反应：发热、寒战、头痛、皮疹，可减慢/暂停输注并对症处理。
  • 严重过敏：喘憋、低血压、喉头水肿等，需停药并急救处理。
  • 血栓/肾损伤：高危患者需充分水化、低速输注并动态监测尿量和肌酐。
  • 神经系统反应：无菌性脑膜炎样表现、高剂量或快速输注时更应警惕。
  • 容量超负荷/TRALI：低氧、肺水肿或心衰患者需特别谨慎。

复评与升级

有效

进入巩固与随访

  • 继续康复、营养、抗癫痫和精神症状管理。
  • 根据复发风险考虑口服激素递减或周期性免疫治疗。
  • 持续肿瘤筛查，尤其抗NMDAR、LGI1、CASPR2等相关情境。
无效/恶化

及时升级

  • 重新审视感染、肿瘤、代谢/毒性和非AE诊断。
  • 与血浆置换统筹顺序，避免清除刚输注的IVIG。
  • 讨论二线免疫：利妥昔单抗、环磷酰胺等。
一句话总结

你前面写的公式是否成立？

成立。如果按2.5 g/瓶计算，总瓶数公式就是：

体重 x 0.4 x 5 ÷ 2.5 = 体重 x 0.8

例如60 kg：60 x 0.8 = 48瓶；每日剂量60 x 0.4 = 24 g，即24 ÷ 2.5 = 9.6瓶/日。临床实际开药要按药房是否允许非整瓶、规格是否为2.5 g、剩余液处理、患者容量耐受来调整。
