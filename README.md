# 自身免疫性脑炎 IVIG（丙球）使用流程图

这是一个可直接部署到 GitHub Pages 的单文件 HTML 页面。

## 文件说明

- `index.html`：网页主体，手机和电脑均可查看。
- `.nojekyll`：告诉 GitHub Pages 不使用 Jekyll 处理，避免静态文件被误处理。

## GitHub Pages 部署方法

1. 新建一个 GitHub 仓库，例如：`medical-notes`。
2. 上传本文件夹中的 `index.html` 和 `.nojekyll` 到仓库根目录。
3. 进入仓库 `Settings` → `Pages`。
4. `Source` 选择 `Deploy from a branch`。
5. `Branch` 选择 `main`，目录选择 `/root`，保存。
6. 等待 1-3 分钟，在 Pages 页面复制访问链接。

常见链接格式：

```text
https://你的用户名.github.io/仓库名/
```

如果仓库名为 `你的用户名.github.io`，则链接通常为：

```text
https://你的用户名.github.io/
```

## 更新页面

以后只需要替换 `index.html`，GitHub Pages 会自动重新发布。
